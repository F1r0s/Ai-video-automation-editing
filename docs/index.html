How this deployment works

  • GitHub Pages serves this HTML page and any other static assets.
  • The scraping step should run on the user’s own device if you want that device IP.
  • Oracle Cloud keeps the video rendering, downloading, and upload pipeline.
  • Future client-side UI can call your Oracle API for status and render jobs only.
This scaffold intentionally avoids backend code, secrets, runtime folders, and generated media.
